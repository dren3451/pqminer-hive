# pqminer-open: отдельный полётник CMP 90HX

Публичные архивы содержат только Hive-скрипты. Бинарники остаются в приватном `dren3451/pqminer` и скачиваются только с GitHub-токеном. Здесь нет токена или бинарника.

## Текущая установка: 0.1.7-open4

| Поле | Значение |
| --- | --- |
| Miner name | `pqminer-open` |
| Installation URL | https://raw.githubusercontent.com/dren3451/pqminer-hive/pqminer-open/codex/pqminer-open-loader3.tar.gz |
| Wallet template | `%WAL%.%WORKER_NAME%` |
| Pool URL | Ваш обычный Pearl pool URL |
| Password | `x` или ваш пароль пула |
| Extra config для проверенной базы | `-a pearl --gh-token github_pat_... --pearl-kernel open` |
| Extra config для нового кандидата | `-a pearl --gh-token github_pat_... --pearl-kernel wide` |

Токен: **Contents: Read-only** для приватного `dren3451/pqminer`. Прежний токен подходит, если у него уже есть доступ. Настоящий токен указывается только в своём полётнике или в `/hive-config/pqminer.token` на риге. Загрузчик удаляет его перед записью конфигурации майнера.

Без явного выбора ядра loader3 по-прежнему запускает legacy. В open4 доступны legacy, прежний open3 (режим open) и новый wide.

## Измеренные результаты пользователя

- open1 / open: около 28 TH/s.
- legacy: 41.75 TH/s в 60-секундном профиле; в логе реального пула ранее была принятая шара.
- open3 / open: **46.68 TH/s**, 198 W, 3072 хеша точны по CPU-эталону. Это примерно +11.8% к legacy в сравниваемых профилях.
- Wide: **ещё не измерен на GPU**. Цель 80–85 TH/s, сравнимая с SRBMiner, пока не достигнута.

Счётчики шар в benchmark синтетические и не доказывают принятие пулом.

Wide использует блок 128x256 и две независимые исходные 8x8 proof-транскрипции на поток. Он повторно использует A-фрагменты, снижая число загрузок на выходную ячейку; счётчик работы, формат пруфа и сложность не меняются. Стартап wide проверяет 7680 хешей по CPU-эталону, включая несколько N-блоков и неполную группу M. При ошибке GPU не начинает майнинг.
